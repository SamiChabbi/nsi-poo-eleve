# NSI Terminale — La programmation orientée objet (version élève)

```
01_Cours_POO.ipynb          le cours
02_Exercices_POO.ipynb      15 exercices tirés de vrais sujets du bac, du plus facile au plus difficile
```

**Comment travailler :**
1. lire le cours, en exécutant les cellules dans l'ordre ;
2. faire chaque exercice **sur papier** d'abord, avec la méthode de la partie 10 du cours ;
3. recopier ensuite son code dans la cellule prévue et lancer la cellule **🧪 Tests** : `✔ Tous les tests passent` = gagné.

Exercices : sujets de l'épreuve écrite du bac NSI 2021 à 2025.
